# CLAUDE.md

As regras de comportamento para trabalhar com o Design System **Nephos** estão em
**[`AGENTS.md`](./AGENTS.md)** — a fonte é uma só, para todos os agentes.

**Regra que não se quebra:** antes de gerar, compor ou alterar qualquer interface
(tela, página, componente, bloco ou HTML), **consulte o `design.md` e as fichas
`componentes/<id>.meta.ts` primeiro** (ou o MCP `nephos-ds`: `nephos_foundations`
→ `nephos_search` → `nephos_get`). Na dúvida: **herdar ou perguntar — nunca inventar valor.**

Ver [`AGENTS.md`](./AGENTS.md) para o fluxo completo, a checagem de fidelidade e as fronteiras.
